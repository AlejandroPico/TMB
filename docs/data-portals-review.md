La referencia nacional más directa es el **[Punto de Acceso Nacional de Transporte Multimodal (NAP)](https://nap.transportes.gob.es/Home/)** del Ministerio. Publica un [mapa de cobertura](https://nap.transportes.gob.es/Home/MapaCobertura), un [API documentado](https://nap.transportes.gob.es/api/index.html?url=%2Fswagger%2Fv2%2Fswagger.json) y conjuntos de operadores. Sus [preguntas frecuentes](https://nap.transportes.gob.es/faqs) indican acceso libre y gratuito sujeto a la licencia. Resulta útil para ampliar redes sin descubrir cada ayuntamiento por separado, pero hay que comprobar disponibilidad, formato, geometría y vigencia de cada conjunto. No implica GPS universal ni sustituye las credenciales de las API operativas.

Prioridad práctica para una ampliación posterior: tiempo real de Moveuskadi mediante servidor, API propia de EMT para llegadas de autobús y catálogo NAP para nuevas redes verificadas. La revisión no modifica calendarios caducados ni convierte estimaciones en posiciones reales.
